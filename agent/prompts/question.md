Use this tool when you need to ask the user questions during execution.

This allows you to:

- Gather user preferences or requirements.
- Clarify ambiguous instructions.
- Get decisions on implementation choices as you work.
- Offer choices to the user about what direction to take.

Usage notes:
A "Type your own answer" option is added automatically; don't include a separate option for free form answers. If you recommend a specific option, make that the first option in the list and add "(Recommended)" at the end of the label
